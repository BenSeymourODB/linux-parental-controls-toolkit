Parental Controls Toolkit

UI / UX design mock-ups

Three consumer surfaces feed one Fastify dashboard and one policy store (see docs/architecture.md). These plain-HTML studies explore what each surface should look like and feel like before the SvelteKit and desktop-app work lands. The supervised-user client dashboard is new territory — proposed here for the first time and written up in design/README.md.

Design principles carried through every surface
🟢 No surprises — the child can always see the rules and what's coming. 🤝 Not punitive — framed as "time left", "earn more", never "blocked / denied". 🔭 Orchestration, not enforcement — UI reflects upstream tools, doesn't reinvent them. 📱 One API — every surface reads/writes the same /api/* contract.
